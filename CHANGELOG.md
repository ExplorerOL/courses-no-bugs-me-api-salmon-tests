## v1.0.0
### Изменено
- тесты переписаны на Python с использованием ООП, паттернов проектирования и лучших практик:
    - перед запуском тестируемое приложение проверяется на готовность к работе
    - имеется одна глобальная конфигурация
    - присутствует очистка окружения перед каждым тестом
    - каждый тест генерирует необходимые тестовые данные
    - заложены точки масшатбирования для добавления классов работы с новыми сущностями
    - используются софт ассерты
    - используются паттерны пректирования (фабрика, фасад, стратегия)
    - тесты понятные и короткие
    - по результатом теста формируется детальный отчет
